## Design Specificity Verdict

Le vocabulaire est spécifique (rails/wells/LED/Pilot Light ; règles écrites natives au produit) ; la couche qui ships porte encore un résidu générique : `colors.stylex.ts:37–87` exporte la matrice six-rôles que DESIGN.md déclare retirée, `Swatch` l'expose, le lab garde les tuiles legacy « fill = variant ». Scan déterministe : 1 advisory (`shadows.stylex.ts:10`, littéral `oklch(0% 0 0)` = base neutre du var `shadow-color`) — faux positif d'intention, architecture « Shadow-Paints-Itself » documentée ; tokenisation P3 recommandée. Overlays visuels : indisponibles (pas d'outil navigateur, pas de serveur, pas d'injection).

## Overall Impression

Un système réellement authored — anneau de focus composé, tokens audités, géométrie canvas-first = craft rare. Mais l'instrument vit encore partiellement sur la grammaire qu'il dit avoir retirée, et l'ergonomie tactile contredit sa propre promesse. La plus grosse opportunité : fermer l'écart entre le langage validé au lab et les tokens/démos qui le trahissent.

## What's Working

1. L'anneau de focus composé (`pressable.stylex.ts:15`) — le halo est fusionné dans la liste d'ombres, le keyboard focus ne fait jamais tomber le lift de repos.
2. La couche tokens auditable — chaque dérivation porte son pourquoi et son calcul de contraste ; la dette est documentée, donc repayable.
3. Sémantique native + géométrie canvas-first — `<input type=range|select|color>`, `<label htmlFor>` partout, roving-tab partagé, canvas comme budget de layout.

## Priority Issues

**1. [P0] Cibles tactiles sous le contrat du kit.** Toggle 34×20 (`Toggle.tsx:39–40`), Checkbox 18×18 (`Checkbox.tsx:41–42`), Slider 14px (`Slider.tsx:51`), Segmented ≈20px (`Segmented.tsx:52`). Touch first-class est le contrat a11y ; rien ne passe 24×24. Fix : hitbox invisible étendue (≥40px, 44 pour primaires), hausser la rangée Slider. → `$impeccable adapt`

**2. [P1] Aucun état d'erreur/invalidité.** Zéro `aria-invalid`, clamp silencieux (`NumberField.tsx:49–53`). Un clamp muet se lit comme un potentiomètre cassé. Fix : `invalid` + `aria-invalid` + ring `colors.error` + slot message ; annonce du clamp au blur. → `$impeccable harden`

**3. [P1] Texte d'état choisi illisible en dark.** Segmented/Radio durcissent `colors.background` sur fill `base` (`Segmented.tsx:69–97`, `RadioGroup.tsx:83–112`) → pire que 2–2.7:1. Fix : généraliser le pattern ink d'amber (inutilisé, `families.stylex.ts:33–34`) → `chooseInk(family)` ≥4.5:1 les deux modes. → `$impeccable colorize`

**4. [P2] Surface de référence = catalogue déguisé en workspace.** Panneau 12-contrôles + matrice exhaustive (`minisynth.tsx:203–371`) ; 4/8 items du checklist cognitif échoués. Fix : 1–2 exemples habillés par widget, matrice dans le lab `Pair`. → `$impeccable distill`

**5. [P2] Matrice six-rôles retirée still ships.** `colors.stylex.ts:37–87`, `Swatch.tsx:36–46`, `Card.tsx:26–44`, tuiles legacy (`laboratory.tsx:353–357`). Fix : supprimer les rôles sauf `error` + `ring`, dériver les inks famille, re-pointer Swatch. → `$impeccable distill`
