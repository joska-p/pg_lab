# randomart

A generative-art workshop: random math expressions become abstract images, still or animated.
You explore grammars more than seeds.

grammar + seed → expression → GLSL → image

## Faces

- **Toy** — new image, play/pause, PNG export, and the history of what was seen.
- **Lab** — seed, grammar weights, size/share, color space, playback, artwork I/O, expression inspector.
