# T03 — Adaptateur (qui devient qui : 1 arête → 2 carrés)

## Objectif

Définir l'adaptateur qui assigne une identité géométrique à chaque élément du graphe résolu : pour chaque arête, déterminer quels carrés elle génère (1 arête → 2 carrés dans le découpage de Slice 1), en s'appuyant sur le placement du moteur géométrique (T02) sans rien coder en dur.

## Critères de validation

- Un module d'adaptateur existe sous `src/engine/adapter/` (ou emplacement conventionnel).
- Pour chacun des trois cas de T01, l'adaptateur produit une affectation cohérente : identité des carrés, arête d'origine, potentiels associés.
- Zéro géométrie codée à la main : l'adaptateur lit le moteur géométrique et le solveur, il n'invente aucune coordonnée ni taille.
- `vp check --fix` passe sans erreur.
- `vp test` passe (tous les tests verts).

## Contraintes

- Ne pas modifier `KirchhoffSolver.ts`, `Graph.ts`, `netlist.ts` ni le moteur géométrique (T02).
- Ne pas toucher à l'interpolateur (T04 : Clock de glaze) ni au renderer (T05) : ce task est strictement scoped sur l'adaptateur.
- L'adaptateur ne calcule pas de géométrie : il gère l'identité ("qui devient qui"), pas la mathématique ("où et de quelle taille" — rôle de l'interpolateur).

## Livrables

- Code de l'adaptateur dans `src/engine/adapter/`.
- Fichier(s) de test couvrant au moins les trois cas de T01.
- Mise à jour de `PROGRESS.md`.
- Commit de fin de session suivant la convention : `feat(smith-tutte): adaptateur 1 arête → 2 carrés`.
