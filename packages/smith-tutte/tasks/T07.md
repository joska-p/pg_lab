# T07 — Vue duale : circuit électrique côte à côte du pavage

## Objectif

Afficher la vue circuit (nœuds = lignes équipotentielles, arêtes = branches de courant) à côté de la vue pavage (carrés), synchronisées via le même graphe. Sélectionner un carré surligner la branche correspondante dans le circuit, et vice-versa.

## Critères de validation

- Deux panneaux côte à côte dans le `Stage` : gauche = pavage (carrés), droite = circuit (nœuds + arêtes).
- Les deux vues dérivent du même `SquareScene` (pipeline unique, source de vérité unique).
- Interaction : survol/sélection d'un carré → surbrillance de l'arête correspondante dans le circuit ; survol/sélection d'une arête → surbrillance des carrés correspondants dans le pavage.
- `vp check --fix` passe sans erreur.
- `vp test` passe (tous les tests verts, aucun test cassé).

## Contraintes

- Ne pas modifier le solveur, `Graph.ts`, `netlist.ts`, le moteur géométrique (T02), l'adaptateur (T03) ni l'interpolateur (T04).
- Aucune géométrie codée à la main : positions et tailles du circuit découlent du même pipeline.
- Réutiliser `CpuCanvas` + `CpuSurface` pour les deux vues (ou un seul canvas avec deux zones).
- Le `ClockStore` reste partagé (une seule animation pour les deux vues).

## Livrables

- Composant `DualView` (ou deux `CpuCanvas` synchronisés) sous `src/components/`.
- Logique de synchronisation sélection/survol (stores ou props).
- Rendu du circuit : nœuds (cercles/lignes horizontales aux potentiels), arêtes (segments verticaux aux courants).
- Tests de la synchronisation si logique pure extraite.
- Mise à jour de `PROGRESS.md`.
- Commit de fin de session suivant la convention : `feat(smith-tutte): vue duale circuit / pavage synchronisées`.
