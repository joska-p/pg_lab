# T06 — Sélection des netlists de test + contrôles de la `Clock`

## Objectif

Exploiter la scène de rendu de T05 sur les trois netlists de test (`simple-edge`, `two-series`, `two-parallel`) et ajouter les contrôles de lecture du `ClockStore` de glaze (play / pause / reset), sans modifier le pipeline de calcul.

## Critères de validation

- Un sélecteur permet de passer d'un netlist de test à l'autre ; chaque cas affiche ses carrés via le même pipeline (netlist → solveur → géométrie → adaptateur → interpolateur → renderer).
- Les contrôles play / pause / reset pilotent le `ClockStore` fourni par `CpuCanvas` (`onClockStore`), et la progression transmise à l'interpolateur reste lue sur la `Clock`.
- Les netlists sont chargés comme assets résolus par Vite (pas de `fetch` sur un chemin absolu), conformément à `codex/docs/conventions/07-patterns-and-project-choices.md` §12.3.
- `vp check --fix` passe sans erreur.
- `vp test` passe (tous les tests verts, aucun test cassé).

## Contraintes

- Ne pas modifier le solveur, `Graph.ts`, `netlist.ts`, le moteur géométrique (T02), l'adaptateur (T03) ni l'interpolateur (T04).
- Aucune géométrie codée à la main : positions et tailles découlent toujours du pipeline.
- Scope strict : interface de sélection et de lecture autour de la scène existante.

## Livrables

- Sélecteur de netlist + contrôles de la `Clock` dans `App.tsx` (et composants associés sous `src/`).
- Netlists de test servis comme assets Vite.
- Tests de la sélection si de la logique pure est extraite.
- Mise à jour de `PROGRESS.md`.
- Commit de fin de session suivant la convention : `feat(smith-tutte): sélection des netlists et contrôles de la Clock`.
